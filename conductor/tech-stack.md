# Tech Stack

This project will utilize the following technologies, frameworks, and libraries:

## Programming Languages:
- Python

## Core Libraries/Frameworks:
- **PyCaret:** The primary library for streamlined machine learning workflows, supporting classification, regression, clustering, timeseries, and anomaly detection.
- **Google ADK (Agent Development Kit):** For building the backend agent to interact with users and orchestrate ML tasks.
- **CrewAI:** For agent orchestration (as indicated in the `GEMINI.md` overview).
- **Streamlit:** For building the interactive user interface (UI).

## Machine Learning Models:
- **Google Gemini Models:** Primarily supported.
- **Future Integration:** Claude, OpenAI models.

## Data Storage & Management:
- **DuckDB:** For storing user conversation history and model running records.

## MLOps & Experiment Tracking:
- **MLFlow:** For tracking experiments, managing models, and MLOps.

## Containerization:
- **Docker:** For containerization, primarily for testing model execution and deployment.

## Cloud Platforms for Deployment:
- Azure
- AWS
- Google Cloud Platform (GCP)
