# Tech Stack: PyCaretAgent

`PyCaretAgent` utilizes a modern, high-performance tech stack focused on automated machine learning and intelligent agent behaviors.

## Core Language & Runtime

- **Python 3.12+**: For its robust ecosystem and support for modern features.

## Machine Learning & AI

- **PyCaret**: Used as the foundational library for automated machine learning tasks (classification, regression, etc.).
- **Google Generative AI SDK (google-adk)**: For defining AI agents, planning, and tool-based interactions.

## Data Management & Analysis

- **DuckDB**: For fast, in-process analytical data management and processing.
- **Pandas/Numpy**: (Indirectly through PyCaret) for data manipulation.

## Development & Environment

- **uv / pip**: For dependency and package management.
- **python-dotenv**: To handle configuration via environment variables.
- **Conductor**: For project management and structured documentation.
