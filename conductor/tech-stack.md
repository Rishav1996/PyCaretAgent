# Tech Stack: PyCaretAgent

- **Language**: Python 3.12+
- **AutoML Core**: [PyCaret](https://pycaret.org/) for automated model selection and evaluation.
- **Agent Orchestration**: [Google Generative AI SDK](https://github.com/google-gemini/google-adk) (`google-adk`).
- **Data Engine**: [DuckDB](https://duckdb.org/) for high-performance dataset analysis.
- **Environment**: `uv` or `pip` for dependency management.
