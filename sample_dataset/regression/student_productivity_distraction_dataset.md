About Dataset
This dataset contains 20,000 student records capturing lifestyle, academic behavior, digital distraction, and productivity metrics.

It is designed to help analyze how modern digital habits such as phone usage, social media, and gaming affect productivity and academic performance.

Features include:

• Study hours per day
• Sleep hours
• Phone usage hours
• Social media usage
• YouTube usage
• Gaming hours
• Stress level
• Focus score
• Attendance percentage
• Exercise minutes
• Coffee intake
• Assignments completed
• Final grade
• Productivity score (target variable)

This dataset is ideal for:

• Regression tasks
• Classification tasks
• Machine learning projects
• Data science practice
• Educational research
• Behavioral analysis

The productivity_score column can be used as the target variable to predict student productivity based on lifestyle and academic features.
