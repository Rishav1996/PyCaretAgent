About Dataset
Synthetic data on mango prices and sales volume.

The dataset is highly suitable for:

📊 Time-series forecasting
🤖 Machine learning price prediction
📈 Demand modeling
🧠 Seasonal trend analysis

This dataset is inspired by the Avocado Prices data by Justin Kiggins

Link : https://www.kaggle.com/datasets/syedaeman2212/mango-prices
