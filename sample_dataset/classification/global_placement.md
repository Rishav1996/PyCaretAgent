About Dataset
Dataset Description
This dataset contains a large global collection of student academic and placement records designed to simulate realistic university-to-career transition outcomes.

It includes detailed student-level attributes such as country, university tier, CGPA, internships, projects, certifications, aptitude score, technical test score, soft skills score, backlogs, specialization, and placement training participation, along with final outcomes including placement status and annual salary in USD.

The dataset is structured to reflect realistic relationships between academic performance, practical experience, skill development, and hiring outcomes across different regions and institution tiers.

What You Can Do With This Dataset
The dataset is suitable for multiple data science tasks, including:

Placement prediction (classification modeling)
Salary prediction (regression modeling)
Feature importance analysis
Internship impact studies
Country-wise salary comparison
Academic performance vs employability analysis
End-to-end machine learning workflows
Dashboard and visualization projects
Data Realism
All numeric indicators follow structured academic and hiring-style statistical distributions so the dataset resembles real-world university placement and recruitment analytics data.

Placement probability is influenced by skill strength, academic performance, internships, and institutional tier, while salary ranges vary across geography, specialization, and company type to reflect realistic market behavior.
